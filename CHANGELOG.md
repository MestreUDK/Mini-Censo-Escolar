# Histórico de alterações

Este projeto mantém a identificação de versão **3.0**. A preparação para o GitHub Pages não altera a versão do aplicativo nem o formato do backup JSON.

## Versão 3.0 — atual

- Gerenciamento de turmas com lista suspensa no cadastro de estudantes;
- Cadastro, renomeação e exclusão de turmas vazias;
- Importação de listas antigas, com identificação automática de turmas;
- Manutenção do gerenciador de categorias de cor ou raça;
- Crédito de autoria no rodapé: Vinícius Oliveira Moraes © 2026.

### Preparação para GitHub Pages (sem alterar versão)

- Renomeado o arquivo principal para `index.html`;
- Acrescentados metadados de autoria e descrição da página;
- Adicionado atalho para baixar o HTML e usar a aplicação offline;
- Esclarecido o comportamento dos dados locais nas versões hospedada e offline;
- Incluídos README, licença educacional com atribuição, `.nojekyll` e `.gitignore`;
- Não foram incluídos dados identificáveis de estudantes.

## Versão 2.1

- Importação de listagens de estudantes com autodeclaração pendente;
- Indicador de alunos pendentes, sem incluí-los nos percentuais do gráfico.

## Versão 2.0

- Inclusão de categorias de autodeclaração personalizadas;
- Cores próprias para as categorias e persistência no backup JSON.

## Versão 1.0

- Cadastro de estudantes, registro por turma, gráfico de pizza;
- Exportação PNG, importação/exportação JSON e armazenamento local.
